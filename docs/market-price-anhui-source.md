# 安徽价格信息网：每周地区均价离线验证

核实日期：2026-10-14。来源为用户提供的 [食品价格查询页](https://ahjgxx.in.ah.cn/jfcx/sp/)。本轮完成少量公开查询及离线解析，未注册自动采集任务，未入库或发布运行行情。

## 新证据与结论修正

此前工具访问安徽网站返回 403，未取得逐商品内容。此次网页工具仍返回 403、内置浏览器连接失败，但本机普通 HTTPS 请求得到 200，并读取查询页、其公开前端脚本和三个查询结果。因此撤销“尚未取得该来源具体价格”的旧判断；工具访问受阻不能解释为网站需要用户 API Key。

页面初始 HTML 只是界面，价格由前端发起只读查询后填入。商品目录、地区目录和价格结果可取得 JSON；这属于网站前端使用的接口，尚未取得稳定开放 API 的服务承诺。本次不需要用户提供账户、密码或额外 API Key。前端访问参数只用于本地研究，没有写入提交的代码、配置或文档。

页面目录实际包含蔬菜、粮油、肉禽蛋、水产品、水果五类。已取得蔬菜 15 个商品和肉禽蛋 7 个商品的目录及规格、单位；没有据此声称五类全部有合肥有效价格，也没有批量查询全部商品。

三个查询均有 20 个真实日期，2026-06-02 至 2026-10-13，本轮所读序列间隔为七天。用户截图选中“安徽省”，其 2.75/1.77 与省级查询相符，不作为合肥价格。元/500克与元/市斤数值相同，不再除以二。

前端明确注明本页数据为全省或各市均价。当前脚本实际使用 `marketPrice=0`，注释和界面将其标为每周监测价格；查询页虽保留每日超市价格标签，本轮未验证该每日分支。每周发布也不能直接推断均价是对整个自然周所有交易计算所得；具体采样量、采样时点、均价方法和统计起止日期仍未知。

来源地区代码 `340100000` 对应合肥市，`340000000` 对应安徽省；系统分别记录为 `340100`、`340000`，不按任意代码截断猜测地区。价格响应没有回显地区，所以原始查询参数和对应响应必须同时保留。离线解析能检查保存的上下文一致性，不能独立证明一个被人为替换的响应确实属于所填地区。

图表与表格是同一份数据，不能计作两个独立来源。不同商品的价格字段 ID 不同，按返回的列标签辨别零售/批发，不能复用青椒的字段 ID 解析鸡蛋。原站图表将零值作为缺报显示，离线预览保留缺报空值，不生成免费商品、补齐日价或插值。

## 已完成的离线工具

- `modules/market-price/backend/anhui-preview.ts`：检查来源页面、查询参数、商品/地区目录、规格与单位，交叉核对图表、表格和最新价，输出两条地区均价参考序列。
- `modules/market-price/scripts/preview-anhui.ts`：只读取本地 UTF-8 JSON，不联网，不读 `.env`，不连接数据库或模型。
- `modules/market-price/tests/fixtures/anhui-weekly-excerpt.json`：两个实际历史日期的最小重建片段，字段 ID 用测试名称替代；不是完整接口响应，不导入运行库。

运行：

```sh
node modules/market-price/scripts/preview-anhui.ts modules/market-price/tests/fixtures/anhui-weekly-excerpt.json
```

输入须包含 `source_url`、原始查询参数 `query`、查询时的商品和地区目录 `catalog`、对应返回数据 `response`。无需将前端认证参数写入输入。仅有价格响应而没有地区/商品查询上下文时，工具会拒绝解析。

输出保留 `publication_frequency=weekly`、`statistic_kind=regional_monitoring_mean` 和未知统计期间，明确 `direct_observation_import_allowed=false`。这些地区均价不能作为单摊报价进入现有 `market_observations` 样本池，也不能由一个地区均价推算 P20–P80 或采样人数。后续经授权接入时，需要独立的监测参考序列保存及展示方式。

实际完整响应验证：三个查询分别输出两条参考序列，每条 20 个点；省/市、青椒/鸡蛋的规格和单位均正确保留。4 项针对性测试全部通过，模块类型检查通过：

```sh
node --import ./tests/standalone.ts --test modules/market-price/tests/anhui-preview.standalone.test.ts
npx tsc -p modules/tsconfig.json
```
