## 新证据与结论修正

此前工具访问安徽网站返回 403，未取得逐商品内容。此次网页工具仍返回 403、内置浏览器连接失败，但本机普通 HTTPS 请求得到 200，并读取查询页、其公开前端脚本和三个查询结果。因此撤销“尚未取得该来源具体价格”的旧判断；工具访问受阻不能解释为网站需要用户 API Key。

页面初始 HTML 只是界面，价格由前端发起只读查询后填入。商品目录、地区目录和价格结果可取得 JSON；这属于网站前端使用的接口，尚未取得稳定开放 API 的服务承诺。本次不需要用户提供账户、密码或额外 API Key。前端访问参数只用于本地研究，没有写入提交的代码、配置或文档。

页面目录实际包含蔬菜、粮油、肉禽蛋、水产品、水果五类。已取得蔬菜 15 个商品和肉禽蛋 7 个商品的目录及规格、单位；没有据此声称五类全部有合肥有效价格，也没有批量查询全部商品。

来源地区代码 `340100000` 对应合肥市，`340000000` 对应安徽省；系统分别记录为 `340100`、`340000`，不按任意代码截断猜测地区。价格响应没有回显地区，所以原始查询参数和对应响应必须同时保留。离线解析能检查保存的上下文一致性，不能独立证明一个被人为替换的响应确实属于所填地区。

图表与表格是同一份数据，不能计作两个独立来源。不同商品的价格字段 ID 不同，按返回的列标签辨别零售/批发，不能复用青椒的字段 ID 解析鸡蛋。原站图表将零值作为缺报显示，离线预览保留缺报空值，不生成免费商品、补齐日价或插值。

## 已完成的离线工具

- `modules/market-price/backend/anhui-preview.ts`：检查来源页面、查询参数、商品/地区目录、规格与单位，交叉核对图表、表格和最新价，输出两条地区均价参考序列。
- `modules/market-price/scripts/preview-anhui.ts`：只读取本地 UTF-8 JSON，不联网，不读 `.env`，不连接数据库或模型。
- `modules/market-price/tests/fixtures/anhui-weekly-excerpt.json`：两个实际历史日期的最小重建片段，字段 ID 用测试名称替代；不是完整接口响应，不导入运行库。

运行：

```sh
node modules/market-price/scripts/preview-anhui.ts modules/market-price/tests/fixtures/anhui-weekly-excerpt.json
```

输入须包含 `source_url`、原始查询参数 `query`、查询时的商品和地区目录 `catalog`、对应返回数据 `response`。无需将前端认证参数写入输入。仅有价格响应而没有地区/商品查询上下文时，工具会拒绝解析。

输出保留 `publication_frequency=weekly`、`statistic_kind=regional_monitoring_mean` 和未知统计期间，明确 `direct_observation_import_allowed=false`。这些地区均价不能作为单摊报价进入现有 `market_observations` 样本池，也不能由一个地区均价推算 P20–P80 或采样人数。

## 后台接入与本地验证

后台入口为 `/admin/market/sources`，新增“安徽监测源”配置按钮。默认源 ID 为 `anhui-hefei-monitoring`，地区为合肥，采集间隔 10080 分钟；首批商品为青椒 `101001`、西红柿 `101005`、鸡蛋 `103007`。`config.adapter=anhui_weekly`，`goods_codes` 可选择最多 10 个不重复商品代码。省级来源需单独创建 `340000` 地区和不同信源，不能修改已有合肥数据的归属。

在线查询流程按公开页面读取脚本、商品类别/规格目录和地区目录，再发起选定商品的每周价格查询。不执行远端 JavaScript，不硬编码网页访问参数，也不将其写入源配置、采集地址记录或错误信息。使用后台统一 HTTP 出口、同源约束、数量上限和查询间隔；校验 robots 的查询页、脚本及数据接口路径。本轮普通请求核实 `/robots.txt` 返回 404，仍不能视作使用许可。

迁移 `0108_market_monitoring_snapshots.sql` 新增独立快照表。快照保留查询参数、对应商品/地区目录及返回数据；同一内容重复采集不新增，源内容修订时追加新版本，保留旧证据。采集任务不会把监测快照送入 AI 文章提取、单条报价校验、日价区间计算或公开报价接口。运行记录的解析/新增计数按商品快照记录，20 个监测日期不算 20 个独立来源。

管理员可从信源行的“监测数据”查看已保存序列，或读取 `GET /api/admin/market/monitoring?source_id=anhui-hefei-monitoring`。该接口沿用管理员鉴权，当前只在管理后台查看；小程序公开监测参考接口不在本次修改范围内。

已有后台数据库完成迁移后，登记默认停用来源：

```sh
node --env-file-if-exists=.env scripts/migrate.ts
node --env-file-if-exists=.env modules/market-price/scripts/register-anhui.ts
```

登记脚本不会覆盖已有同 ID 信源配置。真实采集仍需要来源启用、确认实际使用范围，并开启既有 `COLLECT_ENABLED` 与 `MARKET_COLLECT_ENABLED`；本次没有修改这些开关。来源“预览”可粘贴离线 JSON，预览不保存数据；留空的真实试抓同样遵守已有开关与来源许可检查。
